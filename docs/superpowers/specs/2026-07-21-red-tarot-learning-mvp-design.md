# 빨강타로 학습 MVP 디자인

작성일: 2026-07-21

## 1. 목표

빨강타로는 완성된 점괘를 소비하는 서비스가 아니라, 카드의 기본 의미와 배열 위치, 질문 분야, 카드 간 관계를 연결해 사용자가 스스로 해석하는 방법을 배우는 웹 앱이다.

첫 구현은 다음 학습 흐름을 검증한다.

`홈 → 카드 상세 → 연애 3장 배열 → 직접 해석 → 단계별 힌트 → 카드 연결 → 종합 해설 → 복습 저장`

대표 학습 세트는 전체 조합 데이터가 아니다. 해석 규칙을 익히는 예제이며, 모든 조합을 저장하지 않는다.

## 2. 첫 구현 범위

### 포함

- 반응형 웹 화면 3개: 홈, 카드 상세, 3장 배열 학습
- 메이저 아르카나 22장의 기본 카드 데이터
- 연애 분야 3장 배열 대표 학습 세트 10개
- 정방향과 역방향 표시 및 설명 구조
- 카드 상세의 핵심 의미, 정·역방향, 분야별 의미, 상징 탭
- 단계별 학습: 직접 해석, 카드 힌트, 위치 해석, 연결 문장, 종합 해설
- 이 기기 안에 저장되는 진도, 오답, 즐겨찾기
- 모바일과 데스크톱 화면
- 건강 콘텐츠가 추가될 때 사용할 의료 안전 안내 컴포넌트와 문구

### 제외

- 로그인과 계정 간 동기화
- 결제, 커뮤니티, 실제 상담 예약
- 서버 데이터베이스
- 랜덤 점괘나 미래 사건을 단정하는 기능
- 마이너 아르카나 56장과 전체 150세트의 본문 작성
- AI 자유 채점

제외 항목은 구조적으로 추가 가능하게 만들되, 첫 구현의 화면과 데이터에는 노출하지 않는다.

## 3. 시각 방향

선택된 방향은 `A. 체리 팝`이다.

- 브랜드 색: 선명한 체리 레드
- 바탕: 눈이 편한 크림색
- 보조색: 옅은 핑크와 따뜻한 노랑
- 형태: 통통한 모서리, 작은 스티커형 장식, 명확한 버튼
- 문장: 짧고 친절한 한국어, 어려운 타로 용어는 보조 설명과 함께 사용
- 인상: 매우 예쁘고 귀엽지만, 장식보다 카드와 학습 단계가 먼저 보임

카드 그림은 첫 버전에서 교체 가능한 프레젠테이션 컴포넌트로 분리한다. 저작권이 불명확한 이미지는 포함하지 않으며, 숫자·카드명·상징을 이용한 자체 스타일 카드로 시작한다.

## 4. 정보 구조와 화면

### 홈

- 오늘의 카드와 7분 학습 시작 버튼
- 연속 학습 일수와 전체 숙련도
- 연애·재물·건강 진도 영역
- 최근 틀린 카드와 이어서 학습하기
- 하단 또는 상단 공통 내비게이션

첫 데이터는 연애 학습만 동작한다. 재물과 건강은 다음 확장 범위를 보여주는 비활성 진행 카드로 표시하며, 준비 중임을 분명히 알린다.

### 카드 상세

- 카드 번호, 한국어·영어 이름, 카드 비주얼
- 핵심 동사와 핵심 키워드
- 정방향과 역방향
- 연애·재물·건강 분야별 의미
- 주요 상징
- 흔한 오해
- 즐겨찾기 및 학습 상태 변경

정보를 한꺼번에 펼치지 않고 탭으로 나눈다. 키보드와 터치 모두 사용할 수 있어야 한다.

### 3장 배열 학습

- 연애 질문과 위치: 현재 관계, 상대의 태도, 향후 흐름
- 세 장의 카드와 정·역방향 표시
- 사용자의 직접 해석 입력
- 카드별 힌트
- 위치에 맞춘 해석
- 연결 문장
- 가장 일반적인 해석, 가능한 대안, 조건, 흔한 오해
- 퀴즈 한 문제와 복습 저장

힌트는 순서대로 열린다. 종합 해설을 먼저 열더라도 입력 내용은 유지된다.

## 5. 콘텐츠와 해석 규칙

카드 데이터와 학습 세트 데이터를 분리한다.

카드 데이터는 다음 정보를 가진다.

- 고유 ID, 카드 번호, 한국어·영어 이름
- 중심 동사와 핵심 의미
- 정·역방향 요약과 주의점
- 연애·재물·건강 분야별 정·역방향 의미
- 상징과 흔한 오해

학습 세트 데이터는 다음 정보를 가진다.

- 고유 ID, 분야, 난이도, 배열 위치
- 카드 ID와 방향
- 카드별 분석과 위치 해석
- 카드 연결 문장과 종합 해설
- 대안 해석, 해석 조건, 흔한 오해
- 퀴즈와 정답 근거

해석은 다음 공통 문법을 따른다.

1. 카드의 중심 동사를 찾는다.
2. 동사를 배열 위치의 주어와 연결한다.
3. 질문 분야에 맞는 표현으로 바꾼다.
4. 카드 관계를 강화, 충돌, 원인과 결과, 문제와 해결, 겉과 속으로 분류한다.
5. 세 장의 흐름을 한 문장으로 압축한다.

역방향은 단순한 부정 의미가 아니라 차단, 지연, 내면화, 과잉, 결핍 중 하나로 설명한다.

## 6. 구조와 데이터 흐름

화면, 콘텐츠, 학습 기록을 독립된 영역으로 나눈다.

- 화면 컴포넌트: 공통 내비게이션, 카드 비주얼, 진행률, 탭, 힌트 단계, 안전 안내
- 정적 콘텐츠: 메이저 카드 22장과 연애 학습 세트 10개
- 학습 규칙: 카드 데이터와 위치·분야·관계 정보를 조합하는 순수 함수
- 학습 기록: 브라우저 저장소에 진도, 오답, 즐겨찾기, 마지막 학습 위치를 저장

사용자가 세트를 열면 학습 세트가 카드 ID로 카드 데이터를 참조한다. 화면은 두 데이터를 합쳐 카드와 힌트를 보여주며, 사용자의 입력과 진행 단계는 학습 기록에 저장한다. 카드 본문을 수정해도 세트 구조가 깨지지 않도록 고유 ID를 사용한다.

## 7. 오류와 빈 상태

- 잘못된 카드 ID는 홈으로 보내지 않고, 복구 안내와 카드 도감 이동 버튼을 보여준다.
- 학습 세트가 없으면 빈 화면 대신 준비 중 안내와 카드 학습 링크를 제공한다.
- 브라우저 저장소를 사용할 수 없으면 현재 세션에서 학습은 계속하고, 기록이 저장되지 않는다는 안내만 보여준다.
- 사용자가 종합 해설을 먼저 열거나 입력 없이 진행해도 흐름이 막히지 않는다.
- 건강 문구는 진단이나 치료 결과를 단정하지 않으며, 지속되거나 심한 증상은 의료 전문가의 평가가 우선임을 알린다.

## 8. 접근성과 반응형 기준

- 본문과 버튼은 모바일에서도 읽을 수 있는 크기를 유지한다.
- 색만으로 정·역방향, 선택, 정답 여부를 구분하지 않는다.
- 모든 탭과 버튼은 키보드로 접근 가능하다.
- 애니메이션은 짧게 사용하고, 움직임 줄이기 설정을 존중한다.
- 모바일은 한 열, 넓은 화면은 카드와 설명을 나누는 두 열을 기본으로 한다.

## 9. 검증 기준

- 홈에서 오늘의 카드와 연애 학습을 시작할 수 있다.
- 메이저 22장의 상세 경로가 모두 열리고 잘못된 경로는 복구된다.
- 연애 10세트에서 카드·위치·정역방향·힌트·해설이 일치한다.
- 직접 작성한 해석이 힌트를 열어도 사라지지 않는다.
- 즐겨찾기, 진행도, 오답이 새로고침 뒤에도 유지된다.
- 모바일과 데스크톱에서 가로 넘침이나 가려진 주요 버튼이 없다.
- 키보드만으로 주요 학습 흐름을 완료할 수 있다.
- 건강 안전 안내에는 질병, 임신, 치료 결과의 단정이 없다.

## 10. 이후 확장

첫 흐름이 검증되면 마이너 아르카나 56장, 재물·건강 세트, 1장·5장 배열, 카드 도감 필터, 조합 연구소, 채점 기준, 전체 150세트를 순서대로 추가한다. 카드 콘텐츠와 학습 세트는 같은 스키마를 유지한다.
